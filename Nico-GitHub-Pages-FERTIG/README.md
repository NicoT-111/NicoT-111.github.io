# Nico – GitHub Pages

Dies sind die fertig gebauten Website-Dateien. Keine Installation und kein Build nötig.

1. Alle Dateien und Ordner aus dieser ZIP direkt ins Hauptverzeichnis des GitHub-Repositories hochladen. index.html muss neben assets/ und photos/ liegen, nicht in einem Unterordner.
2. Im Repository Settings → Pages öffnen.
3. Unter Build and deployment: Source = Deploy from a branch; Branch = main; Folder = / (root). Save klicken.
4. Nach erfolgreicher Veröffentlichung die dort angezeigte Website-Adresse öffnen.

Die ZIP selbst nicht als einzige Datei hochladen. Keine benutzerdefinierte Domain nötig. Bei normalen Projekt-Repositories gehört der Repository-Name zur Website-Adresse.
